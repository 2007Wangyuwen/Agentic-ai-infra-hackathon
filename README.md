# Agentic-ai-infra-hackathon

This repo is for Agentic4Systems Track 03: Agentic AI Infra.

## Current modules

- Agent tool-calling demo based on LangGraph
- Experiment memory module based on ChromaDB
- Inference benchmark tool
- Integrated agent workflow prototype

## Goal

Build an agentic workflow that can run infrastructure experiments, collect benchmark results, analyze performance, and store experiences for future optimization.
